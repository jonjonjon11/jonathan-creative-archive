# Check or adapt one example

Copy the plain-text prompts below into your notes, on paper or in a text editor. A name is optional. Use **not tested**, **unknown** or **question** where appropriate. Do not copy the sample answers from the [quick start](../QUICKSTART.md) as if they were observations you made.

```text
Lesson or tool title:
Source link or local file path:
Module/version or exact commit, if known:
Example, exercise or step:
Date of this check:
Contributor name or pseudonym (optional):

Original claim or example:
What I checked, or the one thing I changed:
My prediction before checking:
How I checked (calculation, paper trace, source, or actual tool use):
Result, including units or what the answer counts:
Why I think the result follows:
What differs from the published version:
What I could not check or still do not understand:

Status: proposed observation or adaptation; review pending
Sources consulted (or none):
Original attribution and license:
Changes to describe if sharing:
```

For a mathematical check, include enough steps for someone else to repeat it. For a tool observation, say which settings you used and what actually happened; the [browser report](browser-test-template.md) has more detail. Keep a prediction separate from an observation. If you did not use a browser, say so. A matching answer does not establish learning effectiveness, accessibility or real-world safety.

Keep your notes locally unless you choose to share them. Do not include learner-identifying information, patient data, private conversations or credentials. Follow the [quick start's sharing options](../QUICKSTART.md#4-share-only-if-you-want-to) for optional issues or pull requests and for attribution. Online submission requires a GitHub account and connection; the report itself needs neither.
