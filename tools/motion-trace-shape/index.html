01 · Make a line

Choose Line, then play or scrub. Both motions stay in step. Where is the dot when both positions are zero?

Show what to notice

The dot is at the center. Equal left-right and up-down positions make a diagonal line, traced back and forth. The path is not a new object or a force.

02 · Open it into a circle

Choose Circle. The repeat counts stay the same. What changes when one motion gets a quarter-cycle head start?

Show what to notice

When left-right position is zero, up-down position is at an extreme. When up-down position is zero, left-right position is at an extreme. Equal amplitudes and this offset make a circle.

03 · Find a figure-eight

Choose Figure-eight. The up-down rhythm now repeats twice as often. Predict how many times it reaches the top in 8 seconds.

Show what to notice

Twice. One left-right cycle and two up-down cycles, starting together, draw a sideways figure-eight. Try a different head start: a 1:2 ratio alone does not guarantee this shape.

What this model means, and what it does not

This is a mathematical drawing made from two independent sinusoidal motions, a family called Lissajous curves. It is not a recording of a real object or a claim about quantum particles. There is no gravity, friction, sound or hidden force simulation. Colors distinguish coordinates; they are not physical properties.

Each coordinate reaches one model unit either side of the center. The equal-scale square plot keeps circles circular. We choose an 8-second model window. The controls set the number of repeats within that window, from 1 to 4. These integer counts make the position and direction repeat after 8 seconds, sometimes sooner. The head start is the vertical phase in degrees.

x(t) = sin(2π × left-right repeats × t / 8)
y(t) = sin(2π × up-down repeats × t / 8 + head start × π / 180)

These are analytical formulas, not a numerical integration. The trace uses 481 calculated samples, one every 1/60 model second including both endpoints. Straight segments join them. The live dot is calculated at the selected time, so it can be slightly ahead of the last stored sample. The dashed guide previews the whole window; it is not visited history. Nothing is measured.

Playback speed only changes how quickly you see model time pass. It does not change the equations or exported samples. Animation pauses when the page is hidden. No learning-effectiveness, device-accessibility or physical-safety certification is claimed.

References: OpenStax, Simple Harmonic Motion; Wolfram MathWorld, Lissajous Curve. References open online only if you choose them; the lab itself needs no connection.

Use it without animation, or with a keyboard

Everything begins paused. If your device asks for reduced motion, Still mode starts on. With Still mode on, use Step or the time slider to explore without continuous playback. Tab moves among controls. Enter or Space activates buttons. Arrow keys adjust sliders; Home and End go to their limits. You can use all controls without dragging. Position numbers and the text summary describe the selected moment. Changes are announced when you use a control, not on every animation frame.

Save the equations, parameters, all 481 samples and current display settings to your device. No names, tracking or uploads. Save or share the HTML file to reuse the lab offline.
