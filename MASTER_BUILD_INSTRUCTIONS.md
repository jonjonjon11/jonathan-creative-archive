# Knowledge Commons build instructions

Use [MASTER_PROMPT_FOR_CODEX.md](MASTER_PROMPT_FOR_CODEX.md) as the current contributor brief. It documents the existing files, actual validation commands, editorial standards, review boundaries, and testing limits.

The earlier version of this file described proposed automation as implemented. There is no automatic assembler, automatic merge system, or completed all-subject curriculum. Git history preserves that earlier proposal.

Start with one bounded lesson or review task, preserve the existing format and separate licenses, test what you change, and return evidence for review. The [division lesson](docs/lessons/introduction-to-division.md) and [review task](data/tasks/task-division-review.json) provide a concrete example.
