# Source inventory and coverage

The [manifest](manifest.json) contains stable source IDs used throughout the chapters and concept records. Private conversation, Drive, file and repository locators are withheld from the publication candidate. An exact-locator audit record exists separately for review; it must not be packaged into a public release.

Sources include direct user requests, recovered documents, actual recovered file bytes, delivery records, repository metadata, selected source files, and secondary syntheses. These carry different evidentiary weight. See [evidence rules](../docs/evidence-and-status.md).

The prepublication review found 30 owned source GitHub repositories, all private at inspection, and selected work on non-default branches. This inventory predates the new public compilation repository. It also recovered seven creative-history files and two research/mission packets. These counts describe reviewed/recovered material, not total account output. Most raw inputs remain outside this candidate. The unchanged Reality Atlas standalone is the one reviewed inclusion, with its separate CC0 license and exact hash.

The original Reality Atlas calculation layer was executed in a bounded Node harness and passed 46 focused checks. Fresh Chromium rendering was blocked before page load. All other earlier test counts remain attributed historical reports. Whole-account coverage, full branch/runtime assessment, current deployment availability, scientific validation, and third-party rights remain incomplete.

Public readers will be unable to verify private originals from this edition alone. A future release can add reviewed original artifacts and verified public links without pretending the current summaries already provide that access.
