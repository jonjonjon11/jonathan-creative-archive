# Source inventory and coverage

The [manifest](manifest.json) contains stable source IDs used throughout the chapters and concept records. Private conversation, Drive, file and repository locators are withheld from the publication candidate. An exact-locator audit record exists separately for review; it must not be packaged into a public release.

Sources include direct user requests, recovered documents, actual recovered file bytes, delivery records, repository metadata, selected source files, and secondary syntheses. These carry different evidentiary weight. See [evidence rules](../docs/evidence-and-status.md).

The prepublication review found 30 owned source GitHub repositories, all private at inspection, and selected work on non-default branches. This inventory predates the new public compilation repository. It also recovered seven creative-history files and two research/mission packets. These counts describe reviewed/recovered material, not total account output. Most raw inputs remain outside this archive. The unchanged Reality Atlas standalone, selected cooperation/rescue source files, and Lumen Commons source/generated standalone are separately reviewed inclusions, with separate CC0 licenses and exact hashes.

The original Reality Atlas calculation layer was executed in a bounded Node harness and passed 46 focused checks. Fresh Chromium rendering was blocked before page load. The preserved cooperation/rescue authoring kit also passed its four-mission validator and all 25 tests during fresh archive revalidation. Lumen Commons passed 24 fresh Node tests and static build/source-parity checks; its fresh browser test was blocked before page load. Other earlier test counts remain attributed historical reports. Whole-account coverage, full branch/runtime assessment, current deployment availability, scientific validation, and third-party rights remain incomplete.

Public readers will be unable to verify private originals from this edition alone. A future release can add reviewed original artifacts and verified public links without pretending the current summaries already provide that access.
