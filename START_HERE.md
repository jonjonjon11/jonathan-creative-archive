# Start here

Choose one readable lesson:

- [Introduction to division](docs/lessons/introduction-to-division.md): equal sharing, groups and leftovers, with worked examples and solutions.
- [Motion, traces and shape](docs/lessons/motion-trace-shape.md): coordinate tables and explanations, with an optional offline browser lab.
- [One press, one star](docs/lessons/one-press-one-star.md): predict a pretend game's score on paper, then optionally run and change the Python example.

The [learner quick start](docs/QUICKSTART.md) explains downloading without Git, checking and adapting an example, keeping a private copy, and sharing optional feedback. You do not need an account, programming tools or schema knowledge to read the lessons. An initial download needs a connection; included lesson text works offline afterward.

This is an early, selective archive. The lessons are AI-assisted drafts with scoped mathematical/software checks, not a validated curriculum. Human learner, educator, physical-device and accessibility acceptance remain pending. See each lesson and tool's current review notes rather than treating historical completion reports as approval.

For repository contributors, start with [CONTRIBUTING.md](CONTRIBUTING.md) and the [current contributor brief](MASTER_PROMPT_FOR_CODEX.md). For the broader creative vision and available tools, use [README.md](README.md). Newly authored archive material is [CC BY 4.0](LICENSE); recovered tools keep their separate licenses.
